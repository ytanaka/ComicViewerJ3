RustはUIから get_thumbnail() が呼ばれたら、サムネイルファイルのフルパスを返す。

サムネイルファイル名の作り方
  hash = (オリジナル画像ファイルのフルパス + 画像ファイルサイズ + 画像ファイルの更新日時) のSha256ハッシュの16進文字列
  ファイル名 = {hash}.jpg

サムネイル格納ディレクトリの構造
  app_cache_dir()/thumbnails
    ├─ ...
    └─ {サムネイル作成時の指定サイズ 10進文字列}
      ├─ ...
      └─ {00 - FF} (hashの先頭2文字)
        ├─ ...
        └─ サムネイルファイル
  
  ※ 更新日時が古いサムネイルファイルはバックグラウンド処理で定期的に消す。

get_thumbnail() の処理
  すでにサムネイルファイルが存在すれば、それを返す。
  サムネイルファイルが存在しなければ、UIから指定されたサイズで作成して、それを返す。
  ※ このコマンドが呼ばれたとき、サムネイルファイルの更新日時を現在時刻に更新する。
  ※ サムネイルファイルはランダムな一時ファイルで作成してからリネームする。

get_thumbnail() には画像ファイルだけでなく、ディレクトリを指定できる。

  ディレクトリ指定時のサムネイル作成元画像ファイルの見つけ方
    1. ディレクトリのファイル一覧を取得する
    2. 名前でソートしてリストを作る
    3-a. リストの先頭が画像ならば、サムネイル化する
    3-b. リストの先頭がディレクトリならば、そのディレクトリを指定して 1 に戻る
    3-c. ただし、ディレクトリを3階層下っても見つからない場合は、サイズ0でサムネイルファイルを作成する
    ※ この処理はディレクトリに対するサムネイル画像が見つかったときは行わない

  ディレクトリに対するサムネイルファイル名の作り方
    hash = (指定ディレクトリのフルパス + 指定ディレクトリの更新日時) のSha256ハッシュの16進文字列
    ファイル名 = {hash}.jpg

  サムネイルファイルのサイズが 0 なら、UIにサムネイルなしと返す
